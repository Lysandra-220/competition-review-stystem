面向学院竞赛组织场景的报名与评审管理系统
项目简介
当前学院学科竞赛报名、作品提交、评审打分、成绩统计依赖线下手工统计与表格管理，存在流程分散、信息易丢失、评审流程不规范、数据无法追溯、统计效率低等痛点。本系统采用 Python Flask + SQLite + Bootstrap 开发，实现学生报名、作品上传、管理员审核、专家分配评审、成绩统计导出、操作日志审计一体化全流程管理，提升赛事管理规范化与信息化水平，适配学院真实竞赛使用场景。
系统设计目标
1. 实现学生、管理员、评审专家三角色权限管控，角色权限严格隔离，杜绝越权访问；
2. 完成竞赛全流程闭环：团队报名→作品上传→资格审核→专家批量分配→在线打分→成绩统计→结果公示；
3. 支持3 评委 / 5 评委评审模式，自动去除最高分、最低分计算平均分，贴合真实竞赛打分规则；
4. 实现PDF 文件在线预览、作品分类上传、上传截止时间管控；
5. 提供数据可视化看板、全流程操作日志审计、成绩与日志一键导出；
6. 适配学院 Ubuntu 服务器一键部署，保证系统稳定、安全、可落地。
系统总体架构
• 后端：Flask 框架实现业务逻辑、权限控制、文件处理、数据计算
• 数据库：SQLite 轻量化数据库，存储用户、队伍、文件、评审、日志、公告数据
• 前端：Bootstrap + Chart.js 实现页面布局、数据可视化、交互效果
• 部署：支持本地运行 + Ubuntu 服务器 Gunicorn 生产部署
功能模块设计（与开题完全一致）
1. 用户权限模块
• 学生：团队报名（组长 + 2 名组员）、作品分类上传、查看自身队伍状态
• 管理员：队伍审核、评审专家批量分配、成绩导出、日志管理、公告发布
• 评审专家：仅查看分配给自己的队伍、在线打分、不可重复提交
2. 赛事流程模块
• 团队报名：队伍名称防重复，支持本科生 / 研究生组别选择
• 作品管理：报名表、承诺书、论文正文、附件分类上传，PDF 在线预览
• 资格审核：队伍状态分为待审核 / 已通过 / 已驳回，未通过禁止上传与评审
• 评审分配：管理员批量绑定专家与队伍，实现一对一评审权限
• 在线打分：系统校验不可重复打分，自动核算最终成绩
3. 数据统计与可视化模块
• 数据看板：柱状图 + 饼图，实时展示总队伍、待审核、已通过、已评审数据
• 成绩计算：3/5 评委模式切换，自动去除极值计算平均分
• 成绩公示：公开展示最终排名，支持队伍名称搜索
• 数据导出：成绩表、操作日志一键导出 Excel，文件名带时间戳，自动备份数据库
4. 安全与审计模块
• 密码加密存储，杜绝明文泄露
• 操作日志记录：操作人员、IP 地址、操作内容、操作时间，全程可追溯
• 文件上传防重名、防覆盖，严格校验文件格式
• 全页面权限校验，禁止越权访问
• 会话超时、退出登录，保障账号安全

运行 & 部署步骤
1. 克隆 / 下载项目代码
2. 安装项目依赖
pip install flask==2.3.3
pip install pandas==2.1.4
pip install openpyxl==3.1.2
pip install werkzeug==2.3.7
 
1. 本地运行
执行命令：
python app.py
 浏览器访问：http://127.0.0.1:5000
1. 服务器部署（Ubuntu 系统专用）
执行一键部署脚本：
bash deploy.sh
后台自动启动项目，访问地址：服务器IP:5000
